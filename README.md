# MindVault v0.2 — личный ИИ-компаньон

**Слоган:** Очисти голову. Закрой дела.

Local-first PWA: вторая память + штурман планирования + зеркало состояний.
Реализация этапов 1–5 из [DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md).

## Структура

| Путь | Назначение |
|---|---|
| `src/` | Клиент: Vite + TypeScript (`services` / `stores` / `views`) |
| `server/` | Бэкенд-прокси к LLM (FastAPI, stateless) — см. `server/README.md` |
| `tests/` | Vitest: миграция, семантический поиск, «Эхо мыслей» |
| `legacy/prototype-v0.1.html` | Прототип v0.1 (история) |
| `android/` | Старая WebView-обёртка v0.1 (заменяется Capacitor-сборкой) |
| `capacitor.config.ts` | Конфигурация Capacitor (нативная сборка из `dist/`) |
| `DEVELOPMENT_PLAN.md` | План развития |

## Возможности

**Фундамент (Этап 1):** IndexedDB с версионированием схемы; автоматическая
миграция данных из v0.1 (localStorage) с backup — ничего не теряется;
редактирование мыслей, undo после удаления, swipe-действия, тёмная тема,
импорт/экспорт JSON, голосовой ввод.

**ИИ-ядро (Этап 2):** LLM-категоризация с офлайн-fallback на ключевые слова;
эмбеддинги (хранятся только локально) + семантический поиск на устройстве
(кнопка ✨); чат-компаньон с RAG-памятью по твоим мыслям и summary профиля
(пересборка раз в сутки из данных за 30 дней); ИИ-сводка недели.

**Слои состояния (Этап 3):** чек-ин энергия/настроение/фокус за 10 секунд;
тренды за 14 дней; наблюдения и корреляции (только при достаточном объёме
данных); опциональный анализ тональности записей.

**Планирование (Этап 4):** «Сделать план» — ИИ-декомпозиция мысли на шаги;
weekly review зависших мыслей (сделано / план / отпустить / пропустить).

**Уникальные функции (Этап 5):**
- 🔁 **Эхо мыслей** — приложение замечает возвращающиеся мысли (по эмбеддингам,
  настраиваемый порог), показывает «вес» и предлагает закрыть; ложные
  срабатывания убираются вручную и запоминаются;
- 🕊 **Анти-список** — осознанно отпустить мысль с ритуалом закрытия;
- ⏳ **Капсула времени** — мысль себе в будущее (нативное уведомление в
  Capacitor-сборке, в браузере — при открытии приложения).

Все не-ИИ функции работают полностью офлайн. Без сервера приложение
не деградирует — ИИ-кнопки честно сообщают «офлайн».

## Запуск

### Клиент

```bash
npm install
npm run dev      # разработка
npm run build    # сборка в dist/
npm test         # Vitest
npm run lint     # ESLint
```

### Бэкенд-прокси (нужен только для ИИ-функций)

```bash
cd server
pip install -r requirements.txt
LLM_API_KEY=<ключ Groq/VseGPT/DeepSeek> uvicorn main:app --port 8000
```

Подробности и все env — в `server/README.md`. В приложении адрес сервера
указывается в «Настройки → ИИ → Адрес ИИ-сервера».

### Нативная сборка (Android)

```bash
npm run build
npx cap add android   # требует Android SDK
npx cap sync && npx cap open android
```
