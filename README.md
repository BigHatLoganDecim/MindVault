# MindVault — PWA-прототип

**Слоган:** Очисти голову. Закрой дела.

Это PWA-прототип MVP для теста UX, логики автокатегоризации и общего ощущения приложения **до** сборки финальной версии в MIT App Inventor.

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | Всё приложение (HTML + CSS + JS в одном файле) |
| `manifest.json` | Манифест PWA для установки на главный экран |
| `sw.js` | Service worker для офлайн-режима |
| `icon-192.png`, `icon-512.png` | Иконки приложения |

## Возможности прототипа

- Быстрый ввод мыслей (текст)
- **Голосовой ввод** через Web Speech API (только Chrome на Android, русский)
- **Автокатегоризация** по 6 категориям (поиск ключевых слов)
- Главный список + поиск + фильтр-чипы
- Отметка «Выполнено» по тапу, удаление по долгому нажатию (500 мс)
- Статистика: закрыто за неделю, активные, добавлено сегодня, всего, разбивка по категориям
- Ежедневное напоминание (баннер при открытии после заданного времени)
- Экспорт всех данных в JSON
- Хранение в `localStorage` (аналог TinyDB)
- Установка на главный экран Android как нативное приложение

## Как открыть на телефоне (3 способа)

### Способ 1 — GitHub Pages (рекомендую)

1. Открой репозиторий: https://github.com/bighatlogandecim/mindvault
2. **Settings → Pages**
3. Source: **Deploy from a branch**
4. Branch: **`claude/nailbot-mindvault-pwa-setup-FmDH2`** / `/` (root)
5. Save → подожди 1–2 минуты
6. На телефоне открой `https://bighatlogandecim.github.io/mindvault/`
7. В Chrome: **меню (⋮) → Установить приложение** (или «Добавить на главный экран»)
8. Готово — иконка на рабочем столе, открывается без браузерной строки

### Способ 2 — локальный сервер (если есть Python на пк)

```bash
python3 -m http.server 8000
```
Открой `http://<твой-ip>:8000` на телефоне в той же Wi-Fi-сети.

### Способ 3 — просто файл

Скинь `index.html` на телефон (Telegram, email, USB). Открой через файловый менеджер в Chrome. **Минусы:** не сохранится между перезапусками без сервера, и установка на главный экран не сработает (нет HTTPS).

## Совместимость

- ✅ Chrome on Android (Pixel 7 Pro) — все функции, включая голос и установку
- ✅ Safari on iOS — всё кроме голоса (Web Speech API не работает) и установка через Share → Add to Home Screen
- ✅ Desktop Chrome / Firefox — для тестов

## Ограничения PWA (vs нативного App Inventor приложения)

- **Пуш-уведомления по расписанию** ограничены: реальное «каждый день в 20:00 даже при закрытом приложении» в PWA на Android требует серверной части (Web Push). В прототипе сделан баннер при открытии приложения после заданного времени — для теста UX этого достаточно.
- **Монетизация (AdMob/IAP)** не входит в PWA — она появится только в нативной сборке (App Inventor → RuStore).
- **Голосовой ввод** требует доступа к микрофону и интернета (Google STT в Chrome).
