Политика конфиденциальности

Коротко

MindVault не собирает, не передаёт и не хранит ваши данные на серверах. Всё, что вы записываете, остаётся исключительно на вашем устройстве.

Какие данные обрабатывает приложение

  • Мысли и заметки — хранятся в localStorage вашего браузера / WebView. Данные не покидают устройство.
  • Настройки (время напоминания, флаг онбординга) — также в localStorage.
  • Офлайн-кэш — приложение использует Service Worker и Cache API для работы без интернета. Кэш хранится локально и содержит только файлы самого приложения (HTML, иконки, скрипты).

Разрешения

  • Микрофон (RECORD_AUDIO) — используется только для функции голосового ввода. Аудио не записывается и не отправляется: Web Speech API обрабатывает речь локально или через встроенный движок браузера (Chrome). Разрешение запрашивается только при нажатии на кнопку 🎤.
  • Уведомления (POST_NOTIFICATIONS) — используются только для ежедневного напоминания, которое вы сами включаете в настройках. Уведомления формируются локально без участия внешних серверов.
  • Интернет (INTERNET) — нужен только для первоначальной загрузки приложения с GitHub Pages. После загрузки приложение работает офлайн.

Чего мы НЕ делаем

  • Не собираем аналитику, метрики или статистику использования.
  • Не показываем рекламу.
  • Не передаём данные третьим лицам.
  • Не используем cookies.
  • Не требуем регистрации или авторизации.

Удаление данных

Все данные удаляются:

  • Вручную — через кнопку «Удалить все данные» в настройках приложения.
  • Автоматически — при очистке данных приложения / браузера в настройках вашего устройства.
  • При удалении приложения.

Изменения политики

Если политика конфиденциальности изменится, обновлённая версия будет опубликована на этой странице с новой датой вступления в силу.

Дата последнего обновления: июнь 2026 г.
